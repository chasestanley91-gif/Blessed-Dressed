## 1. Headline finding — the Correction Limit table

Page 3 of the GX catalog ("Jacket Specification") prints a **Correction Limit** table:
the maximum deviation the GX standard pattern service will accept off a base size.

| Contents | Limit (cm) |
|---|---|
| Erect posture | 3.0 |
| Hunched | 3.0 |
| Shoulder | ±2.0 |
| Square | 3.0 |
| Sloping | 3.0 |
| Stoop | 1.0 |
| Chest width | ±1.0 |
| Back width | ±1.0 |
| Armhole depth | −1.0 |
| Front side shoulder | 0.7 / −1.0 |
| Waist | ±2.0 |
| Hip | ±1.0 |
| Sleeve width | ±1.0 |
| Front hem | ±1.0 |

**Three adjustments in Chase's own proven tech pack exceed these limits:**

| Proven adjustment | GX limit | Over by |
|---|---|---|
| Armhole depth **up 2.5 cm** | −1.0 | 2.5× |
| Front chest **−1.5 cm** | ±1.0 | 1.5× |
| Front shoulder **Very Forward** | 0.7 / −1.0 | likely over |

This is not an inference — it is his tech pack read against their printed table.

### Compounding: the size chart couples height to chest
Pages 7–9 size charts progress height *with* chest: chest 110–114 sits at height ~190,
while height 170 sits at chest 90–96. Chase is 170.2 cm with a 111.8 chest, so:

- Start from a **chest-matched base** (110–114 / h190): shoulder ~49.2 vs his finished
  44.5 → needs −4.7 cm against a ±2.0 limit. Back length ~80 vs his 72.5 → −7.5 cm,
  and back length is not even a correctable parameter in the table.
- Start from a **height-matched base** (h170 / chest 90–96): chest short by ~+18 cm
  against a ±1.0 chest-width limit.

Neither route lands inside the published limits. *(Size-chart text was recovered from a
mojibake encoding and decoded by inference — one row verified exactly. Treat the coupling
as directional and have Fukuda confirm the base size rather than relying on this decode.
The correction-limit breaches above stand independently of it.)*

### What this means
The GX standard MTM service is a **size-based adjustment system**, not a
made-to-measure-from-scratch system. It fits bodies that sit on the standard progression.
Chase — and any customer built short-and-broad, which is a meaningful share of his
clientele — falls outside it.

This is precisely why Fukuda's first reply offered a second path: a **proprietary-pattern
MTM system, ~6 months setup, ~600 garments/year guideline**. The correction limits are the
reason that path exists. The two options are not "cheap vs expensive" — they are
"fits standard bodies" vs "fits our bodies".

## 5. Gaps in the price lists — must be asked, do not assume

1. **Full canvas is not on the price list at all.** No construction/canvas line exists.
   Either it is the standard build or it is quoted separately. This is potentially the
   single largest missing number in the jacket.
2. **"Another Buttonhole color *One place ¥570"** — is "one place" per buttonhole or per
   location group? Spread is ¥1,710 vs ¥7,980 on this spec alone.
3. **Irregular instructions ¥800 each** — which of his specified deviations actually trigger
   the charge, and how many.
4. **Shirt contrast inner fabric** (placket / collar stand / cuff / top collar / yoke) and
   **bias cutting** — not priced anywhere.
5. **Hexagonal 2-button cuff** — not in the listed cuff options.
6. **Machine pick stitch vs AMF hand stitch** — his tech pack specifies 0.15×0.6 double pick
   stitch. Confirm which line that maps to; the difference is ¥2,300 on every jacket.
7. **MOQ, price breaks, and payment terms** are not on either list.

## 6. Recommended next move

Send the completed spec sheet back and ask for a **line-item quotation against that exact
specification** — not a generic price. That converts every unknown above into a number.

In the same message, put the correction-limit question directly:

> Our reference build is 170.2 cm with a 111.8 cm chest and a 44.5 cm finished shoulder.
> Which GX base size would you cut for this, and what are that size's shoulder width and
> back length? Our proven pattern requires armhole depth up 2.5 cm and front chest −1.5 cm,
> which we note exceed the correction limits printed on page 3 of your catalog. Can these be
> accommodated within the standard service, or does this body type require the proprietary
> pattern system you described? We would also like a quotation for a basted first article.

His answer to that one question determines whether EXCY is a standard-service supplier or a
proprietary-pattern partner — and therefore whether the ~600 garments/year commitment is on
the table now or later.

**Do not disclose target pricing.** Let them quote the spec first.
