# Shirt Drafting Manual — Master Block & Component Formulas

_Authored by the brand owner, 2026-08-01. Verbatim. This document is LAW for the options it names; illustrations and other descriptions aid, not direct._

---

What you're asking for is essentially:

A cutter's drafting manual for every shirt option in the Blessed&Dressed system.

The challenge is that "all shirt options" likely means 100+ individual collar, cuff, placket, back, sleeve, pocket, yoke, hem, dart, and construction variants, which would be several hundred pages.

A real patternmaker's manual would be organized by pattern component family, because each option derives from a base block.

## MASTER SHIRT BLOCK

Everything begins from the basic shirt body.

Variables:

    NC = Neck Circumference
    CC = Chest Circumference
    WC = Waist Circumference
    HC = Hip Circumference

    SL = Sleeve Length
    CW = Cuff Width

    SH = Shoulder Width
    AD = Armhole Depth

    E = Ease

Common ease:

    Chest Ease
    = 8cm to 14cm

    Waist Ease
    = 6cm to 12cm

    Hip Ease
    = 6cm to 12cm

## COLLAR DRAFTING SYSTEM

Every collar derives from:

    Neck Length
    +
    Stand Height
    +
    Fall Height
    +
    Spread Angle
    +
    Point Length

Formula:

    Collar Length

    =
    NC ÷ 2
    +
    Button Overlap
    +
    Extension

Example:

    NC 40cm

    40 ÷ 2

    =
    20cm

    +2.5cm overlap

    =
    22.5cm collar draft

### LONG POINT 8.5cm

#### Geometry

    Point Length = 8.5cm

    Spread = 50°

    Tip Angle = 20°

Draft:

              /\
             /  \
            /    \
           /      \
          /        \

Formula:

    Point Projection

    =
    L × cos(S/2)

Example:

    8.5 × cos(25)

    =
    7.7cm

Visual drop becomes substantial.

## COLLAR STAND

### 3cm

Draft rectangle:

    Length = Collar Length

    Height = 3cm

Curvature:

    0.8cm rise at CB

### 5cm

Draft:

    Height = 5cm

Back rise:

    1.2cm-1.5cm

Must be heavily curved.

Otherwise collar gaps away from neck.

## COLLAR ROLL

Roll line:

    35%

of total collar height above seam.

Example:

    3cm stand

    Roll

    =
    1.05cm
    above attachment seam
