Important tailoring note:

What you're asking for approaches professional patternmaking. A true production pattern also requires body measurements, ease allowances, balance corrections, pitch, posture adjustments, seam allowances, shrinkage allowances, and fitting iterations. No written specification alone guarantees a wearable jacket. However, I can give you the geometric drafting framework that a cutter would recognize.

## Jacket Geometry System

I'll define everything from a drafting block.

    C  = Chest Circumference
    W  = Waist Circumference
    S  = Seat Circumference

    SH = Shoulder Width
    BL = Back Length

    NW = Neck Width
    ND = Neck Drop

    AH = Armhole Depth
    SW = Scye Width

    LW = Lapel Width

    GP = Gorge Point
    BP = Break Point
