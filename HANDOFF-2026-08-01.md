## PIPELINE ORDER — getting this wrong wastes credits silently

```
tools/set_description.mjs                       edit the catalog by option id
  -> extract_spec.mjs --orientation=X --write   REQUIRED: spec.json caches the description
  -> build_prompt.mjs --write
  -> validate_prompt.mjs                        gates BEFORE any credit is spent
  -> generate -> record_generation.mjs
  -> grade -> tools/log_qc_batch.mjs            REQUIRED before regenerating
```

Both failure modes below happened on 2026-08-01, and both are silent:

1. **Skipping `extract_spec --write` after a description change.** `build_prompt` alone rebuilds from
   the cached copy. The "rebuilt" prompt came back byte-identical at 5007 chars, still containing a
   sentence that had just been deleted from the catalog.
2. **Regenerating without logging QC.** `record_generation.mjs` auto-increments the attempt number
   from any prior `qc.json`. With none logged, attempt 2 was written as attempt 1 and **overwrote
   candidate-1.png**. Recoverable from git (the prior `generation.json` carries the CDN URL), but the
   provenance chain breaks. Log QC first, or pass `--attempt` explicitly.

## The two lessons that generalise

**The recurring defect is not bad reasoning about garments. It is sound reasoning that stopped at a
boundary.** A NO-TIE rule argued in full for shirt collars and never applied to waistcoats or lapels.
An `EXCLUSIVE_SHAPE_FAMILIES` mechanism built for exactly this problem, declaring two families out of
five. Six documented photography rules that lived only in reference files and never reached the prompt
string. A snapshot README asking the operator to refresh copies by hand. Every one was found by asking
*does the rule reach the artifact?* — never by re-reasoning about tailoring. When something is wrong,
check the pipeline boundary before rethinking the garment.

**A measurement is only evidence once you have checked that it measures the thing you named.** Earned
four times in one session on one option: a 139px depth inside a 140px box; two drawing measurements
disagreeing in *direction* because both read lapel edges instead of the welt; 290-of-290 "usable"
columns because the lapel ran through the box. Two measurements disagreeing is not a reason to pick
one — it means neither is validated. Crop the region and look at it.
